# 词匣 · The Lexicon

一个纯静态、本地优先的中文单词记诵网页。用文件夹收纳单词本，用单词本收纳词条，再用「依稀 → 未识 → 新词」的队列完成每日复习。

界面采用深色档案纸、复古衬线字与自动生成的几何封面；设计气质参考《重返未来：1999》，但这是一个独立的个人学习项目。

直接双击 `index.html` 即可运行，**不需要安装、不需要 npm、不需要启动服务器**。

## 功能一览

### 词库主页

- 默认打开词库主页，而不是记诵页。
- 文件夹以红色页签和红色高亮边框呈现，点击后自动展开其中的单词本并滚动到单词本区域。
- 单词本以自动生成的 SVG 几何封面展示，封面由书籍 ID 和名称稳定生成，不依赖外部图片。
- 顶部搜索框支持按单词本标题、副标题、说明和所属文件夹搜索。
- 搜索结果会显示所属文件夹，并自动定位到第一本匹配的单词本。
- 支持新建文件夹、新建单词本、删除空文件夹和删除单词本。

### 词条册

在记诵页右上角点击「词条册」打开单词本索引：

- 新增词条。
- **编辑词条**：点击词条右侧的铅笔按钮，打开与新增相同的表单；所有字段会预填当前词条内容，保存后保留原词条 ID、状态和创建时间。
- **切换状态**：点击词条右侧的状态标签，可在「新词 / 依稀 / 未识 / 已斩」之间切换；切换状态会同步复习队列、词库统计和记诵档案。
- 删除词条，并弹出确认框。
- 导出当前单词本为 JSON。

编辑词条时如果修改单词拼写，已有的记诵档案记录也会同步显示新的词形。

### 记诵页

- 队列严格按 **依稀 → 未识 → 新词** 排序。
- 已斩词条完全移出复习队列，也不写入记诵档案。
- 大字号中央单词、音标、词性、释义、例句、译文和出处。
- 支持系统语音朗读当前单词。
- 键盘操作：`←` / `→` 切换，`K` 斩，`F` 依稀，`A` 未识。
- 全部词条都斩完后会显示空状态，可返回词条册或词库。

### 本地音乐

- 唱片卡片里的「选择音乐」展开可折叠的「唱片架」。
- 唱片架会列出 `music/` 目录中的内置唱片，也可以从本机导入音频。
- 导入支持多个文件；文件保存在浏览器 IndexedDB，不重新导入；选中的唱片会跨刷新恢复。
- 内置两首合成环境曲：`archive-waltz.wav`（档案圆舞曲）和 `night-rain.wav`（夜航雨声）。
- 支持播放/暂停、进度、音量、循环和音效总开关。
- 所有音频只在本地播放，不会上传。

## 快速开始

1. 下载或克隆本仓库。
2. 双击 `index.html`，用现代浏览器打开。
3. 点击任意红色文件夹，选择一本单词本。
4. 在记诵页右上角打开「词条册」开始新增或编辑词条。

无需安装依赖。若浏览器限制 `file://` 的本地存储，可以改用任意静态文件服务器托管整个目录；项目本身仍是纯静态文件。

```text
  overlays.css          词条册、档案、本地音乐和确认框

  seed.js               内置文件夹、单词本和词条
  art.js                确定性 SVG 几何封面生成器
  store.js              localStorage、v1 迁移、复习队列和增删改查
  audio.js              Web Audio 音效、目录/导入唱片与播放偏好
  app.js                页面渲染、交互流程、视图切换和词条管理

  archive-waltz.wav     内置唱片：档案圆舞曲

AGENTS.md               面向后续维护者的项目约定
入口.html               最初的设计参考页，不属于应用
```

## 数据与隐私

主数据保存在浏览器的 `localStorage`：

- 键名：`word-lexicon-v3`
- `folders`：文件夹
- `books`：单词本与其中的 `words`
- `activity`：只记录「依稀 / 未识」的温习动作
- `ui`：当前选中的文件夹和最后一次打开的单词本

首次打开时如果存在旧版 `word-lexicon-v1`，会自动迁移内置词状态、旧的自建词条和历史记录，并保留旧键。

本地音乐使用单独的存储：

- `word-lexicon-music-selected-v1`：选中的唱片 ID
- IndexedDB `word-lexicon-music-library`：导入的音频 Blob
- 音量、循环和音效偏好各自保存在 `word-lexicon-*-v1` 键中

应用没有账号系统、云端同步、统计上报或网络请求。所有词条、记录和音频只留在本机。

## 键盘快捷键

| 场景 | 操作 |
| --- | --- |
| 词库页 | `/` 聚焦搜索 |
| 记诵页 | `←` / `→` 切换单词 |
| 记诵页 | `K` 斩，`F` 依稀，`A` 未识 |
| 所有弹窗 | `Esc` 关闭 |

## 技术约束

- 纯 HTML / CSS / JavaScript，经典 `<script src>` 加载，无构建步骤。
- 零运行时依赖，不用 CDN、外部字体或远程图片。
- 字体只使用系统宋体、衬线和等宽字体。
- 数据模型和旧版迁移由 `scripts/store.js` 统一处理。
- 所有封面与界面装饰均在本地生成或由 CSS 绘制。

## 说明

- 本项目是个人学习项目，与《重返未来：1999》官方无关。
- 本地音乐文件不会上传；刷新后选中的唱片会恢复，但浏览器可能要求用户再次点击播放。
- 删除词条、单词本或文件夹前会弹出确认；删除单词本会同时移除它的记诵记录。
