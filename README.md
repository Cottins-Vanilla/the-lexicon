# 词匣 · The Lexicon

一页式的单词记诵应用，使用深色档案与复古几何风格。直接双击 `index.html` 即可离线使用，不需要安装依赖或启动服务。

## 体验流程

1. **词库主页（默认页面）**：查看文件夹，点击红色文件夹展开其中的单词本。
2. **搜索**：在顶部搜索框里输入书名、主题或文件夹名称，结果会自动定位到匹配的单词本。
3. **开始记诵**：点击单词本封面进入记诵页。队列按「依稀 → 未识 → 新词」排序。
4. **词条管理**：在记诵页右上角打开「词条册」，可以新增或删除词条，也可以把已斩词条重新放回复习。
5. **档案**：右上角档案按钮查看依稀、未识的温习记录；已斩词条直接移出复习队列，不写入温习记录。

## 数据结构

数据保存在浏览器 `localStorage` 的 `word-lexicon-v3` 中，包含：

- `folders`：文件夹
- `books`：单词本；每个单词本包含 `words`
- `activity`：仅记录「依稀 / 未识」的温习动作
- `ui`：当前选中的文件夹、最后一次打开的单词本

旧版本 `word-lexicon-v1` 中的自建词条与学习状态会在第一次打开时自动迁移。

## 快捷键

- 词库页：`/` 聚焦搜索
- 记诵页：`←` / `→` 切换单词，`K` 斩，`F` 依稀，`A` 未识
- 所有弹窗：`Esc` 关闭

## 说明

- 所有内容只保存在本机浏览器，不会上传。
- 本地音乐：`music/` 内置唱片与导入音乐都只留在本机，不会上传；导入文件保存在 IndexedDB，选中的唱片会被记住并在下次打开时自动恢复（不自动播放）。
- 字体使用系统内置宋体/衬线字体与样式化排版，无外部网络依赖。
